# Sakura Editor Dictionaries

Downloadable Hunspell dictionary artifacts for [Sakura Editor](https://github.com/BosnaZmaj/sakura-editor).

See the **Releases** tab for available dictionaries. The Sakura Editor app downloads them on demand via **Workspace → Spellcheck → Download Expanded Dictionary…**.

The dictionaries are built from the [English Speller Database](https://github.com/en-wl/wordlist) (formerly SCOWL) by Kevin Atkinson, under the notice in each release's README file.

Build scripts and hashes live in the private sakura-editor repo under `tools/`.
